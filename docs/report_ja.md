# 適応型ドローン巡回点検

2026年10月13日 / 学習済みの経路選択と飛行制御を組み合わせた、3地点点検タスク

## 1. 目的と独自の設計

設備点検では、巡回途中に緊急度や移動条件が変わることがある。本課題はA・B・Cの3地点について、現在観測できる優先度と論理移動コストから次の未訪問地点を選び、ドローンを実際に飛行させる。点検は位置・速度条件を満たす滞在として定義し、センサによる設備測定そのものは模擬していない。

独自性は、学習済みの次地点選択、外部目標を安全に観測へ反映するアダプタ、物理到達後の更新境界、および映像と証拠ログの同期にある。提供ノートブックの飛行PPO・録画手順を継承し、単一目標から3地点の連続巡回へ拡張した。将来のイベント情報を与えず、訪問済み地点をマスクする。

## 2. 学習と目的関数

上位はCPUのMaskablePPO、下位はGenesis/RSL-RLのPPOで、別々に学習した。上位の観測は現在地点、訪問済みフラグ、位置・距離、現在の優先度・有向辺コスト、名目経過時間など65要素。行動はA/B/Cの離散選択で、全地点終了後は方策に問い合わせない。下位は17要素の観測から4モータの操作を出力する。

各脚の目的コストは、距離×有向辺倍率と、地点優先度×名目点検完了時刻の和である。α=β=1、名目速度1 m/s、サービス0.50秒、基地帰還なし。論理倍率は経路ペナルティで、物理速度、電力、障害物を意味しない。報酬はその負値、上位の割引率は1.0とし、全脚のコスト和との一致をテストした。

3シード42/43/44で各50,176静的ステップと50,176イベント混合ステップを実行した。混合比は静的50%、優先度更新25%、コスト更新25%。最初の点検完了後に観測済み状態からイベント値をサンプルする。最終モデルは検証用100例のイベント応答などからシード43を選び、テスト前に固定した。

## 3. 未使用シナリオでの比較

同一の静的100例と動的50例を各シードで比較した。学習方策の目的コストは3シード平均で静的28.717±0.247、動的31.357±0.215。全例で完了率100%、無効行動0。標準偏差はシード平均間の値であり、同じシナリオを繰り返した300/150測定を独立標本とは扱わない。

固定A-B-Cに対する平均差は静的-6.118、動的-4.054だった。貪欲法に対する差は静的+0.165、動的+0.038で、学習方策の優位性は一貫しない。静的のRL/厳密最適コスト比は平均約1.041。動的の選択変更率は各シード14%、12%、14%だった。これらは名目モデルの結果で、実飛行の最速・最省電力を示さない。

## 4. 実物理による到達・再計画の検証

RTX 5060 Ti 16 GBで、32環境・2反復のスモーク後、ノートブックと同じ256環境・301反復で飛行方策を再学習した。初期スモーク録画では7回のリセットがあり、能力の証拠としては用いなかった。本学習モデルの4秒再生はリセットなしで、外部1目標、連続2目標、3シードの連続3目標も成立した。

到達は半径0.20 m以内・速度0.30 m/s以下の連続0.20秒、点検完了は同条件で合計0.50秒とした。逸脱時は保持をやり直す。落下、リセット、非有限値、目標不一致、通信異常、タイムアウトは失敗になる。目標変更による機体の移動・リセットは行わず、目標相対観測を次の推論前に更新した。実GPUテストでも位置・前操作の保持、リサンプリング停止、リセット前状態の捕捉を確認した。

同じ固定モデル対・座標・初期状態・判定条件で、通常、緊急更新、コスト更新を各3回実行し、全9試行で3地点を完了した。通常の順序はA→C→B、時間6.05秒、実軌跡3.718 m。緊急更新とコスト更新はA→B→C、時間6.30秒、実軌跡3.986 m。初期条件が同じためシード間の軌跡は同一で、少数のこの試験は広い信頼性を保証しない。

Aの実点検完了2.09秒の境界で、緊急ケースはBの優先度を1から5、コストケースはA→Cの倍率を1から5へ変更した。更新後の選択は両方ともBで、同一境界の更新なし推論はCだった。これはプランナーの反実仮想比較であり、別の物理飛行ではない。デモ設定は独立のデモ用シード40,000–40,099を2例検索して事前に固定した、説明用の例である。

## 5. 証拠、動画、限界

9試行それぞれに実Genesis生動画、テレメトリ、フレーム時刻表、到達・更新・選択ログを保持した。全生動画をデコードし、全訪問が物理サービスイベントと対応し、フレームが同一実行のシミュレーションステップを参照することを検証した。提出映像は日本語HUDと実軌跡を重ねた120秒のH.264動画である。短い実巡回を観察用に低速再生し、倍率を明記する。架空の飛行や未実施の訪問は加えない。

目的コストは抽象的な近似で、実飛行時間・距離との違いがある。地形・障害物・知覚・バッテリー・実機は未検証。設備点検は滞在のみで、実際の不具合検出は行わない。動的な厳密オラクルは用いず、学習方策が貪欲法や静的厳密解を上回るという主張もしない。

GPU実行フェーズは合計1,233.70秒（約20分34秒）で、許可された8時間以内だった。初期化、学習、再生、録画、テストを台帳で管理し、同時GPUジョブは実行しなかった。最終レビュー修正後にもGPU契約テストと9巡回を再実行して全件成功し、その最終記録を提出映像に用いた。GPU処理は終了したが、レンタルサーバの課金自体は停止していない。成果物をローカル保存してハッシュで検証する。
