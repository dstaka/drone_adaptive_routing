## 3. 今回許可する物理修理と許可しない変更

- 0.30 m固定長リンク、実荷物、受動関節、実質量・慣性・衝突、機体への反力・反モーメントという物理モデルは維持してください。
- このモデル内で、失敗したEuler関節を別の受動関節・拘束表現へ置き換える調査と実装を許可します。pinned Genesis1.4.3でnative spherical/ball articulationが実際に動くかを第一候補として調査し、対応しない場合は同じ物理モデルの対応constraintを検討してください。球関節で直ると決めつけないでください。
- importer変更でDrone専用motor APIを使えない場合は、新specの範囲で4ローターの等価な推力・反トルクadapterを実装できます。ただし番号、spin、座標系、適用点、推力/反トルク係数、RPM mapping、root意味を実測し、元の機体特性と無荷物等価性を検証してください。rootへ単純に合力だけを加えて反モーメントを省くことは不可です。
- 固定リンクは圧縮を伝え得る近似です。張力だけのロープを検証したとは主張しないでください。
- 飾り、位置/姿勢の強制補正、人工的揺れ打消し、隠れたcontroller、荷物への直接制御、強い未説明damping、モーター権限拡大で代替しないでください。
- tension-only rope、柔軟chain、依存版変更、荷物範囲や長さ・配置の変更は許可していません。必要なら根拠と修正specを具体化し、その変更だけ明示確認してください。
