# Controller and measurement contract (Revision3 completion)

Revision3 selects this unchanged controller and MuJoCo as the final primary. Genesis and C/H comparison are no longer completion prerequisites; no flight NN is required. Final acceptance and fresh human video review remain separate gates. The original technical contract below is development evidence for [the versioned specification](../specs/2026-10-23-suspended-payload-hybrid-genesis/spec.md), not final acceptance or hardware transfer evidence.

The first controller, `C-local-lqr-v1`, is a discrete local LQR designed by central finite differences on the unchanged **nominal** MuJoCo model (45 mm cube, mass ratio 0.20). Design-time dynamics are privileged; case-specific true load properties are never runtime inputs. A zero-order motor action is held for the external 0.01 s interval, with body-frame motor transformations evaluated by the unchanged qualified RK4 adapter at its internal stages. No direct payload force, pose overwrite, added damping or increased motor limit is used.

Runtime measurements are drone position/velocity, and drone/link/box body-to-world quaternions and world angular velocities. These are explicitly **ideal simulator sensors**, without demonstrated real-world availability. No mass, size, inertia, seed, bank ID, future event, generalized coordinates or generalized velocities enter the controller. A filtered dictionary is constructed before each control call. Checker-only native generalized coordinates are used to audit the measurements. Delay/noise robustness remains untested.

The 20-dimensional state contains ten local position/rotation coordinates and ten velocities: drone translation, drone attitude, the two transverse relative link rotations, and the two transverse relative box rotations. Angles are rotation vectors in radians; angular velocity is radians/s; translation uses metres and metres/s. Ball rates are represented in each child body frame. Axial joint symmetry coordinates are excluded from the LQR design, but **full three-axis box angular speed** remains in every settling predicate and audit. There is no sensor clipping or undocumented temporal filter.

The nominal gain and hover action are saved as complete JSON tensors for each run. An altitude-error integral, initialized to zero for every physical reset, adjusts the four nominal hover actions equally. Its coefficient is 0.04 per metre-second and its action bound is ±0.12. Integration freezes if saturation would worsen; it is updated once per external control interval. Retargeting preserves the integral, motor history and physical state. This is measurement-history adaptation, not access to the true load.

A quintic reference joins the measured drone position to the actual commanded destination, with bounds of 1.2 m/s, 0.8 m/s² and 2 m/s³, and a minimum three-second reference duration. Intermediate reference values never count as destinations and never restart leg deadlines. All actual commands still come from the inherited routing NN and fixed scenario coordinates.

Actions are bounded to [-1, 1] before the original four-motor map `RPM = (1 + 0.8 action) × 14468.429183500699`. Preclip actions, saturation, integral state, reference, measurements, native state and commanded target are recorded. The optional correction interface is defined as three bounded world-frame acceleration-reference values (±0.5 m/s² each), converted to reference displacement by the declared 1.2 s⁻² scale. Zero correction reproduces C. No correction optimizer has yet been admitted or run; this interface is not an NN performance result.

The live profile is `payload-settling-video-v1`; the strict historical profile is computed independently as a shadow on the same event stream. No aggregate simulated deadline applies to the new mission consumer or checker. The legacy defaults and old evidence retain their original strict predicates and 120 s cutoff. Initial physical reset starts the 600 s mission wall clock; a target command starts its 30 s leg clock. Terminal evidence enqueue and final flushing are recorded separately.
